# AETHERION 2.0 — Changes

- Replaced the previous weighted-overlap retrieval formula with BM25-style lexical ranking, length normalisation, direct-term coverage and calibrated scores.
- Added deterministic morphology normalisation and expanded explicit synonym handling for paraphrased queries.
- Improved PowerPoint extraction for grouped shapes and speaker notes; improved Word extraction for headers and footers.
- Corrected quantity-question responses so they return source statements rather than the number of retrieved passages.
- Added regression tests for paraphrased learner/borrowing questions, overdue/late-fee wording and quantity answers.
- Added active processing stages, animated transmission state, ingestion feedback, progressive evidence reveals, orbit/halo motion, animated archive rows and smoother navigation transitions.
- Added reduced-motion handling.
- Removed stale baseline screenshots from the distributable package so they are not mistaken for Aetherion 2.0 screenshots.
